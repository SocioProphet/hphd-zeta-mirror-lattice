# HPHD Zeta Mirror Lattice

Archival and reproducibility repository for HPHD zeta mirror-lattice work, explicit-formula decompositions, regularized density, and BSD-adjacent analytic-number-theory experiments.

## Initial lanes

- docs/: manuscript/spec sections
- experiments/: reproducible experiment records
- scripts/: executable reproduction scripts
- notebooks/: exploratory notebooks
- data/: raw and processed experiment artifacts
- figures/: generated plots
- src/: reusable library code
- tests/: regression and validation tests
